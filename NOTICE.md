## Claude Design

Everything in `kit/` was generated by [Claude Design](https://claude.ai/design) from a
package that `pipeline/build-ds-bundle.mjs` builds out of the `@nuxt/ui` sources, and then
exported from the platform unchanged. This repository never edits `kit/` by hand.

## The bundle's global name

`kit/_ds_bundle.js` exposes its components under one global name, declared in the bundle's
header and in the `namespace` field of `kit/_ds_manifest.json`. The platform derived it from
the design system's name and the first six characters of the id of the project where the
kit was generated, and the same name is written into the kit's component cards and
`ui_kits`.

It is kept as is: six characters of an id give no access to the project, renaming would
break the byte-for-byte match with the platform, and a rebuild on the platform would replace
any name anyway. See [docs/import.md](docs/import.md#do-not-let-the-platform-rebuild-the-kit).

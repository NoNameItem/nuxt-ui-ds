AuthForm — Nuxt UI 4.11.1 `UAuthForm`; classes come straight from themes/auth-form.ts.

```jsx
<AuthForm>Content</AuthForm>
```

Slots (each is a prop taking ReactNode): root, header, leading, leadingIcon, title, description, body, providers, checkbox, select, password, otp, input, separator, form, footer

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

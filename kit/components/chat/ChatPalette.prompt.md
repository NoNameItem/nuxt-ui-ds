ChatPalette — Nuxt UI 4.11.1 `UChatPalette`; classes come straight from themes/chat-palette.ts.

```jsx
<ChatPalette>Content</ChatPalette>
```

Slots (each is a prop taking ReactNode): root, prompt, close, content

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

DashboardPanel — Nuxt UI 4.11.1 `UDashboardPanel`; classes come straight from themes/dashboard-panel.ts.

```jsx
<DashboardPanel size="true">Content</DashboardPanel>
```

Variants: `size` (true | false)

Slots (each is a prop taking ReactNode): root, body, handle

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

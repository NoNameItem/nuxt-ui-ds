DashboardSearchButton — Nuxt UI 4.11.1 `UDashboardSearchButton`; classes come straight from themes/dashboard-search-button.ts.

```jsx
<DashboardSearchButton collapsed="true">Label</DashboardSearchButton>
```

Variants: `collapsed` (true)

Slots (each is a prop taking ReactNode): base, label, trailing

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

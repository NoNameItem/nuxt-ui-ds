DashboardToolbar — Nuxt UI 4.11.1 `UDashboardToolbar`; classes come straight from themes/dashboard-toolbar.ts.

```jsx
<DashboardToolbar>Content</DashboardToolbar>
```

Slots (each is a prop taking ReactNode): root, left, right

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

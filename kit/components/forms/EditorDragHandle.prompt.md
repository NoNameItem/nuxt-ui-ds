EditorDragHandle — Nuxt UI 4.11.1 `UEditorDragHandle`; classes come straight from themes/editor-drag-handle.ts.

```jsx
<EditorDragHandle>Content</EditorDragHandle>
```

Slots (each is a prop taking ReactNode): root, handle

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

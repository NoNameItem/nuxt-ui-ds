PageAside — Nuxt UI 4.11.1 `UPageAside`; classes come straight from themes/page-aside.ts.

```jsx
<PageAside>Content</PageAside>
```

Slots (each is a prop taking ReactNode): root, container, top, topHeader, topBody, topFooter

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

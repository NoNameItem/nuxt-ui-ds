PageHeader — Nuxt UI 4.11.1 `UPageHeader`; classes come straight from themes/page-header.ts.

```jsx
<PageHeader title="true">Content</PageHeader>
```

Variants: `title` (true)

Slots (each is a prop taking ReactNode): root, container, wrapper, headline, title, description, links

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

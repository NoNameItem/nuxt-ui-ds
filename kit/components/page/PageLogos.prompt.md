PageLogos — Nuxt UI 4.11.1 `UPageLogos`; classes come straight from themes/page-logos.ts.

```jsx
<PageLogos marquee="false">Content</PageLogos>
```

Variants: `marquee` (false)

Slots (each is a prop taking ReactNode): root, title, logos, logo

Override any slot with `ui={{ slot: "classes" }}`. Overlays take `open` as a prop — no behaviour.

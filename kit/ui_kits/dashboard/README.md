# Dashboard kit

Recreation of the Nuxt UI Pro dashboard template.

- `index.html` — interactive: switch Home / Inbox / Settings in the sidebar, open the command palette (search button), toggle dark mode in the navbar, switch toolbar tabs.
- `DashboardApp.jsx` — shell + views. Shell classes are lifted verbatim from `dashboard-sidebar.ts`, `dashboard-panel.ts`, `dashboard-navbar.ts`, `dashboard-toolbar.ts`; Button, Badge, Card, Input, Avatar, Kbd, Alert, Progress and Icon come from the design system.

Not reproduced: resizable panels, real routing, real data.

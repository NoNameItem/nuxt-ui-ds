# Marketing (SaaS landing) kit

Recreation of a Nuxt UI Pro landing page.

- `index.html` — sticky blurred header with dark-mode toggle.
- `LandingPage.jsx` — hero, logo wall, feature grid, pricing, inverted CTA, footer. Section padding and type scale are lifted from `page-hero.ts`, `page-section.ts`, `page-card.ts`, `container.ts`.

Logos are set in type: the source archive contains no logo assets.
